### [Ayn](https://github.com/faridahtarek/ayn) | Drip Irrigation Funding Platform *(In Active Development)*
**Connecting companies with small Egyptian farmers to fund the switch to drip irrigation**

Most small farmers in Egypt can't afford a drip irrigation kit up front, while companies need real, verifiable sustainability projects to report. Ayn connects the two: a cooperative officer registers a farm with an installer's quote, a company funds the kit and sets a reward for the farmer, and once the installation is proven and confirmed, the reward is released. The farmer gets the kit with no debt, and the company gets a farm-by-farm record for its sustainability report.

**Key Features**:
- Role-based accounts for cooperative officers and companies
- Farm registration and management by officers
- Companies browse, filter and fund farms waiting for a kit
- Proof-of-installation upload and company review (confirm or reject)
- Company dashboard tracking funded farms and total feddans switched to drip

**Architecture**:
- **Frontend**: React
- **Backend**: Node.js / Express REST API
- **Database**: MongoDB with Mongoose
- **Auth**: JWT login with hashed passwords

### [AWS Cloud Portfolio](https://github.com/faridahtarek/BI_CloudProject) | Cloud Computing Project
**Full-stack profile management app built for deployment on AWS**

A team project for my cloud computing course: a web app where users manage profiles with image uploads, designed around a full AWS architecture, from networking and permissions through to storage, compute and monitoring.

**Cloud Architecture**:
- **Networking**: VPC with a public subnet, Internet Gateway and Security Groups
- **Security**: IAM role attached to the EC2 instance (instance profile, no access keys)
- **Storage**: Amazon S3 for uploaded images; DynamoDB / RDS for profile data
- **Compute**: Amazon EC2 running Amazon Linux 2023
- **Monitoring**: CloudWatch logging for the server

**Tech**: React, TypeScript, Node.js / Express, Vite, Tailwind CSS, AWS
